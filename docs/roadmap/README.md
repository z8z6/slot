# 限制与演进建议

## 已知限制

1. Texture 当前只生成单级 mip，远距离像素纹理会产生闪烁。
2. 仅实现方向光，尚无点光、聚光、阴影和光源空间分区。
3. 3D 对象/网格动态变化仍不会自动重建对应 GPU 缓冲。
4. 单 allocator 且每帧等待 Fence，CPU/GPU 不能多帧并行。
5. OBJ 忽略 UV/法线/材质且仅支持 16 位索引。

## 推荐顺序

1. 引入 Frame Resource、逐帧 allocator/常量区/fence。
2. 为纹理生成 mip，并增加点光/聚光与阴影。
3. 扩展模型导入，再完善 UI 控件、事件和物理。

修改 CPU/HLSL 共享结构时必须核对字段顺序、16 字节打包及 CBV 256 字节对齐；修改矩阵时必须同时验证转置和 `mul` 顺序；修改资源状态时应使用 D3D12 Debug Layer 验证。
